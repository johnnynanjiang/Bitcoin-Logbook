Open source: the code behind Bitcoin Logbook

The website, the Bitcoin DCA calculator, its daily price file and its tests are all public on GitHub. Every calculation and every trade can be checked.

The two repositories

02

How to run the code

There is no build step. The site is plain HTML, CSS and JavaScript. No Node.js, npm or bundler is needed to use or deploy it. Clone the repository and open any index.html in a browser. The calculator even works straight from disk (file://).

git clone https://github.com/johnnynanjiang/Bitcoin-Logbook.git
cd Bitcoin-Logbook

# Run the calculator's tests (Node.js, no packages to install)
node apps/bitcoin-dca-calculator/tests/run.js

# Or open the same tests in a browser
open apps/bitcoin-dca-calculator/tests/index.html

# Add the latest daily prices (Python 3, no packages to install)
python3 .github/scripts/update_btc_prices.py

The calculator's formulas are in lib/core.js, with one folder per strategy in strategies/.

03

Where the data comes from

  • Calculator prices: Coin Metrics Community Data, metric PriceUSD, the BTC/USD close for every UTC day from 18 July 2010. File: btc-usd-daily.csv.
  • Updated every day by a GitHub Actions workflow. It appends the new days, runs the test suite, and deploys only if the tests pass. The data is cross-checked against Coinbase Exchange daily closes.
  • Journal trades: transcribed from the source workbook, which you can download with the article's CSV files.

Why open source?

"Don't trust, verify".

You shouldn't have to take my word for it. Every number on this site, from a calculator result to the reported +$4,629.81 profit, comes from code and data you can read, run and check yourself.

If a formula is wrong, you can see it. If a price is wrong, you can trace it to the source. If you find a problem, open an issue.
