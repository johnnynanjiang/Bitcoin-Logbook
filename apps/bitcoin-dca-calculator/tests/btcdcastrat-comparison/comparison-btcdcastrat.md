# Bitcoin DCA calculator comparison: Bitcoin Logbook (A) vs BTC DCA Strat (B)

- **A:** <https://bitcoinlogbook.com/apps/bitcoin-dca-calculator/> (live site, data 18 Jul 2010 – 16 Nov 2026, 5,966 daily closes)
- **B:** <https://btcdcastrat.vercel.app/> (live site, data 18 Jul 2010 – 16 Nov 2026)
- **Run on:** 17 Nov 2026 (AEDT). Both pages were driven through their real forms in a browser: fields set, the Calculate / Simulate button clicked, results read from the page.
- **Data source:** both use Coin Metrics Community `PriceUSD` daily closes (CC BY-NC 4.0).

## Summary

**A and B agree in all 100 runs.** Purchase count, amount invested, fees, final value, profit, return and valuation price are identical in every run, except the formatting cases below. The largest relative difference in any number is 3.4e-09.

Why the 29 "≈" runs differ:

1. **Price precision (26 runs).** A stores each daily close at 10 significant digits (e.g. 2012-10-05: A `12.75221942`, Coin Metrics `12.7522194190532`). B uses the full-precision API value. That moves the 8th BTC decimal by a few units, and a few cents on very large values: run 10, $10 a day since 2010, ends at $1,328,339,665.20 vs $1,328,339,665.18. **Check:** B's own engine (`engine.js`), run in Node on A's price file, gives the same purchases, BTC and lump-sum BTC as A in **100 of 100** runs. The schedule and maths are the same; only the stored prices differ.
2. **Display format below $1 (2 runs: 9 and 88).** A shows sub-dollar prices to 4 decimals (`$0.0952`); B rounds to cents (`$0.10`). The underlying numbers agree.
3. **Tiny fee display (1 run: 71).** $1 monthly with a 0.1% fee = $0.002 in fees. A displays `$0.00`; B displays `$0.002`.

## How the runs were chosen

- 16 hand-picked edge cases (runs 1–16) and 84 random ones (fixed seed 20261117). Edge cases:
  - A's default and B's default
  - the three $100/month windows quoted on A's page
  - monthly starts on the 29th, 30th and 31st (month-end rule), and a 29 Feb leap-day start
  - the first day of data (2010), and the full history bought daily
  - start = end, and buying at the 2017 and 2021 peaks
  - the 30% and 4.30% fee rows from A's fee table
- Frequencies: daily 18, weekly 25, fortnightly 28 (B: "Every 2 weeks"), monthly 29. Amounts from $1 to $10,000; fees 0–5% (56 runs with a fee) plus the 30% edge case. Dates span 2010–2026.
- B was set to *Amount type: Per purchase*, Animate off. A ran *Standard DCA*.
- **Lump sum:** B shows it next to every result. For A, the same total was run again with Strategy = *Lump sum* (A's page no longer shows the lump-sum note).

Each output cell is: `buys · invested · BTC · average cost · final value · return · valuation (end) price · lump sum BTC / lump sum value`.
